Faster control, and wall switch changes show up right away. With only one dimmer, the SG app can't connect at the same time.

Signal to Homey

Only the dimmer showing "Direct" needs a good signal. If it is weak, move Homey closer to one of the dimmers.

Other SG devices

Have another SG device named @NDxxxx? Try to add it and use it a little. Then right away press "Create diagnostics report" on the app page, below Configure.

Troubleshooting

Only when the developer asks for it. Turn it off again before you send a diagnostics report.
