Tested with the first generation SG LEDDim Smart rotary dimmer. Other older SG dimmers named @NDxxxx may work. Have another SG device named @NDxxxx? Try to add it and use it a little. Then right away press "Create diagnostics report" on the app page, below Configure.

Homey Pro controls the dimmers directly over Bluetooth, no gateway or bridge needed. Add one device per dimmer, and a group for all if you like. On/off and dimming are supported. When the dimmers are kept connected, wall switch changes show up in Homey right away. Commands are encrypted with the network password, usually 1234. The warning "Possibly wrong network password. See settings." most often means that "Network Isolation" is on in the SG app: turn it off there, which sets the password back to 1234. If you have your home's password, you can instead enter it in the settings of every dimmer: they all need the same one.

Requires Homey Pro. Does not work with Homey Bridge or SG Smart 3.0. With SG Smart 3.0, use SG Smart Gateway 3.0 to connect the lights to Homey with Matter. The app is unofficial and not made, approved or supported by SG. It builds on CSRmesh work by nkaminski, fromm1990, einaros and erlwes. The source code is open.
