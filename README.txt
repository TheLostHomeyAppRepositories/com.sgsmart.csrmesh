Tested with the first generation SG LEDDim Smart rotary dimmer. Other older SG dimmers named @NDxxxx may work.

Homey Pro controls the dimmers directly over Bluetooth, no gateway or bridge needed. Add one device per dimmer, and a group for all if you like. On/off and dimming are supported. When the dimmers are kept connected, wall switch changes show up in Homey right away. Commands are encrypted with the network password, usually 1234. This can be changed in the device settings.

Requires Homey Pro. Does not work with Homey Bridge or SG Smart 3.0. With SG Smart 3.0, use SG Smart Gateway 3.0 to connect the lights to Homey with Matter. The app is unofficial and not made, approved or supported by SG. It builds on CSRmesh work by nkaminski, fromm1990, einaros and erlwes. The source code is open.
